CREATOR CARD PORTER

Privacy & data use

Last updated: July 17, 2026

Capture is manual and local. The extension reads the selected creator page only after you click Capture current page. It has no developer-operated upload or analytics service.

Data handled

A capture can contain character or Lorebook text and settings, image URLs, resource identifiers, and a capture time. The current page URL is checked only to verify support and identify the selected character or Scripts editor; it is not retained as browsing history.

This includes complete creator-form records, including source fields that do not have a target form mapping.

In experimental Other mode, the extension reads recognizable native form controls on the selected page after the capture click. It does not guess or probe API endpoints on an unknown site.

On JanitorAI creator edit pages, the extension reads source data already loaded into the editor. It does not read, copy, or export the page's authorization token.

Chats, passwords, cookies, authorization headers, and API keys are not collected.

Purpose and retention

Captured data is used only to preview field mappings and create the JSON file you request. Captured sources are kept in local extension storage so separate character and Lorebook pages can be combined. If the complete source cannot be stored, the extension reports an error instead of silently truncating it.

Data remains until you choose Clear captures or uninstall the extension. A file leaves the browser only when you explicitly copy, download, or share it.

Permissions

activeTab
Temporarily identifies the tab you selected.
scripting
Runs the capture helper only after you click the capture button.
storage
Keeps selected sources locally until you clear them.

Diagnostic console logs

For troubleshooting, the extension writes capture lifecycle metadata to the selected page's DevTools Console with the prefix [Creator Card Porter]. Logs can include the source type, resource identifier, capture strategy, counts, and failure stage. They never include captured field values, full response bodies, cookies, authorization tokens, or request headers.

Open source

Creator Card Porter is an independent open-source utility maintained through community contributions. References to supported services are descriptive compatibility labels only; names and marks remain with their respective owners.

Privacy questions can be sent through the support contact on the Chrome Web Store listing or raised in the public source repository.
